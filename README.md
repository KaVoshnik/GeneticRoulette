# Рулетка генетических болезней — мод для Casualties Unknown

В начале каждого нового забега крутится рулетка и выдаёт случайную болезнь (или «Здоров»).
Болезнь сохраняется вместе с забегом и возвращается после «Продолжить».

## Болезни (8)
| Болезнь | Эффект |
|---|---|
| ВИЧ (хроническая иммунная недостаточность) | шанс заражения ран ×3 |
| Гемофилия | кровотечение ×1.8, свёртывание ×0.4 |
| Астма | приступы раз в 2.5–5.5 мин: падает кислород (не ниже 72) и выносливость |
| Тугоухость | постоянная потеря слуха (минимум 45 из 100) |
| Нарколепсия | внезапный сон раз в 2–5 мин с предупреждением, предметы выпадают, через 20 с будит |
| Хрупкие кости | сила ударов по конечностям ×1.45 |
| Дальтонизм (красно-зелёный) | матрица дейтеранопии через URP ChannelMixer |
| Ахроматопсия | насыщенность −100 через URP ColorAdjustments |

Красно-зелёный дальтонизм сделан без своего шейдера и AssetBundle: игра использует URP,
а в нём уже есть ChannelMixer. Мод создаёт свой глобальный Volume с приоритетом 1000.

## Установка
1. Поставь BepInEx 5 (x64, Mono) в папку игры, запусти игру один раз, закрой — появится `BepInEx\core`.
2. В `GeneticRoulette.csproj` проверь `GameDir` или собери так:
   `dotnet build -c Release -p:GameDir="D:\Games\Casualties Unknown"`
3. Сборка сама копирует `GeneticRoulette.dll` в `BepInEx\plugins\GeneticRoulette`.
4. Запусти новый забег. Список болезней — F7, принудительный бросок рулетки прямо сейчас — F8 (для теста).

## Настройки
`BepInEx\config\geneticroulette.casualtiesunknown.cfg` — язык (ru/en/auto), число бросков (1–3),
шанс «Здоров», все множители и интервалы.
Для теста: `ForceDiseases = Asthma,Narcolepsy` выдаёт нужные болезни без случайности.

## Сохранения
Игра пишет один `save.sv` и удаляет его при загрузке, поэтому болезни лежат отдельно:
`%USERPROFILE%\AppData\LocalLow\Orsoniks\CasualtiesUnknown\GeneticRoulette.txt`.
Если файла нет (сейв создан до мода), при «Продолжить» болезнь выбирается заново.

## Известные ограничения
- Мод не компилировался и не запускался в игре: у меня не было .NET и самой игры в рабочем виде.
  Все обращения к классам игры (Body, Limb, SaveSystem, PlayerCamera, WorldGeneration)
  сверены с Assembly-CSharp.dll по метаданным, но первый запуск стоит проверить и прислать лог
  `BepInEx\LogOutput.log`.
- Рулетка не ставит игру на паузу.
- Иконок статусов (moodle) нет: болезни показываются в окне по F7.
